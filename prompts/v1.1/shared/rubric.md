# Evaluation Rubric

All scores are integers 1 to 5 with the following anchors. Justifications must be 2 to 5 sentences and cite concrete evidence from the manuscript — do not speculate.

## 1. Methodological rigor

- **1** — Fundamentally flawed design. Conclusions cannot follow from the methods as described.
- **2** — Important methodological issues (e.g., no control group where needed, selection bias unaddressed, insufficient sample).
- **3** — Competent methodology with identifiable gaps (e.g., single-center only, missing sensitivity analysis, confounders partially addressed).
- **4** — Solid methodology appropriate to the question; minor limitations acknowledged.
- **5** — Rigorous, well-controlled, state-of-the-art for the study type; limitations fully addressed.

## 2. Statistical appropriateness

- **1** — Wrong tests applied; results unsupported by the analysis.
- **2** — Statistical approach partially justified; no correction for multiplicity where needed; effect sizes missing.
- **3** — Adequate statistical methods; confidence intervals and p-values reported; minor issues (e.g., missing power calculation).
- **4** — Correct statistical approach with effect sizes, confidence intervals, multiplicity correction as needed.
- **5** — Exemplary statistical treatment including pre-specified analyses, handling of missing data, sensitivity analyses, and appropriate inference.

## 3. Level of evidence (Oxford CEBM 2011 hierarchy)

Classify the study's Oxford LoE on the 1a–5 scale. This is a classification, not a scored dimension.

| LoE | Typical design |
|---|---|
| 1a | Systematic review of randomized controlled trials |
| 1b | Individual randomized controlled trial |
| 2a | Systematic review of cohort studies |
| 2b | Individual cohort study or low-quality RCT |
| 3a | Systematic review of case-control studies |
| 3b | Individual case-control study |
| 4  | Case series, low-quality cohort, or case-control |
| 5  | Expert opinion, mechanistic reasoning, basic science |

Preclinical / cell line / animal studies map to **5**.

## 4. Clinical / translational relevance

- **1** — No clear path to clinical impact; scientific curiosity only.
- **2** — Mechanistic interest; translational path speculative.
- **3** — Plausible translational implications but not demonstrated.
- **4** — Direct clinical or translational relevance; findings inform practice, guidelines, or near-term development.
- **5** — Practice-changing or paradigm-shifting findings with clear applicability.

## 5. Novelty / originality

- **1** — Duplicative; adds no new knowledge.
- **2** — Incremental confirmation of known findings.
- **3** — Meaningful extension of prior work in one direction.
- **4** — Novel question, method, or combination; fills a documented gap.
- **5** — First-in-class discovery, new mechanism, or field-defining contribution.

## 6. Reporting-standard adherence

Identify the applicable reporting standard for the study type and score adherence.

| Study type | Standard |
|---|---|
| RCT | CONSORT |
| Observational | STROBE |
| Biomarker / prognostic | REMARK |
| Systematic review / meta-analysis | PRISMA |
| Preclinical / animal | ARRIVE |
| Prediction model | TRIPOD+AI |
| Diagnostic accuracy | STARD |

Score 1 to 5:
- **1** — Little recognizable adherence; major sections missing or misreported.
- **2** — Partial adherence; some key checklist items absent.
- **3** — Most key items present; a few moderate gaps.
- **4** — Thorough adherence; minor omissions only.
- **5** — Full or near-full adherence; checklist items explicitly addressed.

## 7. Writing and presentation

- **1** — Unclear, disorganized, or ungrammatical to the point of impeding evaluation.
- **2** — Readable but with substantial clarity, organization, or figure-quality issues.
- **3** — Adequate; main points communicated; some sections could be tightened.
- **4** — Well written and organized; figures and tables communicate effectively.
- **5** — Excellent clarity, precision, and structure; publication-ready.

## 8. Data and code availability / reproducibility

- **1** — No data or code shared; methods irreproducible as described.
- **2** — Limited sharing on request only; methods lack replication detail.
- **3** — Some data or code available; protocols generally reproducible.
- **4** — Data and code in recognized repositories; sufficient detail for replication.
- **5** — Full open data, open code, containerized analysis, or equivalent.
